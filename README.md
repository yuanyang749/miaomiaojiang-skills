# Miaomiaojiang Skills (喵喵酱技能库)

这是 [OpenClaw](https://github.com/openclaw/openclaw) 智能助手 **喵喵酱 (Miaomiaojiang)** 的开源技能库。

## 已包含技能

### 1. [Miaomiaojiang Perplexity Research](./miaomiaojiang-perplexity-research)
基于 Perplexity AI 的实时联网搜索与研究工具。支持每日 AI 资讯、GitHub 趋势发现以及深度专题研究。

---

## 快速开始

### 1. 克隆仓库
```bash
git clone https://github.com/yuanyang749/miaomiaojiang-skills.git
cd miaomiaojiang-skills
```

### 2. 配置 API Key
在环境变量中设置 Perplexity API Key：
```bash
export PERPLEXITY_API_KEY="your-api-key-here"
```

### 3. 使用示例 (Perplexity Research)
```bash
cd miaomiaojiang-perplexity-research
python3 research.py --mode news
```
